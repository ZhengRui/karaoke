# 红日卡拉OK视频 — 设计文档

**日期**: 2026-06-16
**场合**: SoarHigh 头马俱乐部 2026-06-18 例会结尾，集体演唱李克勤《红日》
**目标**: 把降了人声的伴奏 + 会员照片滚动背景 + 同步歌词字幕，渲染成一个可双击播放的 MP4。

## 1. 成品 (Deliverable)

- 文件: `red_sun_karaoke.mp4`
- 规格: 1920×1080, 30fps, H.264 + AAC
- 时长: 跟随伴奏音频长度 (~285s / 4:45)
- 现场用法: 笔记本/投影双击播放，演唱者跟唱。零网络、零现场调试依赖。

## 2. 输入素材 (Inputs)

| 素材 | 路径 | 说明 |
|------|------|------|
| 伴奏 | `separated/htdemucs/red_sun/remix.wav` | demucs 分离后降低人声的版本，作为最终音轨 |
| 歌词 | `lyrics.lrc` | 已带时间戳的 LRC，逐句单时间点 |
| 照片 | `photos/1.jpg` … `photos/21.jpg` | 21 张，混合横竖向（约 13 横 8 竖） |

时间戳对齐：`remix.wav` 与 `lyrics.lrc` 同源自 `red_sun.mp4`，故 LRC 时间轴与伴奏对齐。

## 3. 画面设计 (布局 A)

### 3.1 照片背景
- 满屏背景，缓慢推拉 (Ken Burns)：每张轻微放大/平移制造动感。
- 每张停留 ~6.5s，相邻照片之间 1s 交叉淡化 (xfade)。
- 21 张循环铺满整首歌（约 2 遍）；第二遍打乱顺序，减少“刚见过”的重复感。
- 收尾：最后一句 `[04:28.67] 哦` 之后，照片继续播放直到音乐结束。

### 3.2 竖照片处理：模糊补边 (Blurred Fill)
- 横照片：缩放裁切铺满 16:9 全屏。
- 竖照片：原图完整居中（不裁人），左右空白用**同张照片的模糊放大版**填满。
- 判定：宽/高比 < 16/9 视为需补边。

### 3.3 字幕 (特大 · 滚动)
最终采用**滚动歌词**(用户确认):任意时刻显示两句——
- **当前句**：特大字号(84),暖黄高亮 `#FFD24A`,描边+阴影,居中。
- **下句**：白色 ~60% 不透明、缩小到 ~62%,紧贴当前句下方。
- **切句动画(~0.3s 快速,其余时间静止)**：当前句**原地快速淡出消失**(不上飘,且在下句到位前已消失,无重叠)→ 下句**升到中间、放大、变金黄**成为当前句 → 下下句**升入下方淡入**成为新的下句。
- 实现：每句一个 ASS Dialogue,用 `\move`(位移)+多段 `\t`(缩放/变色/透明度)+ `\an5` 中心锚点。每句作为"下句"出现于上一句开始时刻(第一句提前 `intro_lead` 秒)。
- 时间轴：当前句被唱区间 = 该句 LRC 时间到下一句时间；前奏(0~21s)无字。
- 字体：CJK 字体(macOS 实测无 PingFang,使用 STHeiti / "Heiti SC",经 `fontsdir` 由 libass 加载)。

## 4. 技术架构

一个 Python 脚本编排 ffmpeg（`build_video.py`），分阶段产出，便于微调与重跑。

### 4.1 组件

1. **LRC → ASS 字幕生成器** (`lrc_to_ass`)
   - 输入：`lyrics.lrc`。输出：`build/subtitles.ass`。
   - 解析时间戳，跳过元数据行（标题/词/曲）。
   - 为每句生成两条 ASS Dialogue 事件：当前句样式 + 下一句预读样式。
   - 样式集中定义（字号、颜色、描边、底边距），方便调参。

2. **照片归一化 + 片段生成** (`make_clips`)
   - 输入：`photos/*.jpg`，按序 + 第二遍乱序。
   - 每张：probe 宽高判向 → ffmpeg 生成 1920×1080 带推拉的短片段。
     - 竖图：背景分支 = scale cover + crop + blur + 压暗；前景分支 = scale contain 居中；overlay 合成；再 zoompan 做轻微推拉。
     - 横图：scale cover + crop 后 zoompan 推拉。
   - 输出：`build/clip_XX.mp4`（无音频，30fps，固定时长）。

3. **拼接 + 转场** (`assemble`)
   - 用 xfade 把片段链式串接（1s 交叉淡化），循环到 ≥285s 后裁到音频长度。

4. **合成输出** (`finalize`)
   - 烧录 `subtitles.ass`（libass `subtitles` 滤镜）。
   - 合入 `remix.wav`，以音频时长为准（`-shortest` 或显式裁剪）。
   - 导出 `red_sun_karaoke.mp4`。

### 4.2 数据流
```
lyrics.lrc ──► lrc_to_ass ──► build/subtitles.ass ─┐
photos/*.jpg ─► make_clips ─► build/clip_*.mp4 ─► assemble ─► build/bg.mp4 ─► finalize ─► red_sun_karaoke.mp4
remix.wav ─────────────────────────────────────────────────────────────────┘
```

### 4.3 中间产物
- 全部放 `build/`，可清理重跑。脚本支持只重跑某阶段（如只改字幕样式时跳过照片渲染）。

## 5. 错误处理与边界
- 照片数量变化：脚本动态读取 `photos/` 目录，不写死 21。
- 某张照片损坏/无法 probe：跳过并告警，不中断整体。
- 音频/视频时长不齐：以音频为准，背景不足则继续循环、超出则裁切。
- 字体缺失：脚本启动时检查 CJK 字体可用性，缺失则报错给出替代字体名。

## 6. 可调参数（集中在脚本顶部常量）
- 每张照片时长、交叉淡化时长、推拉幅度。
- 字幕：当前句/预读句的字号、颜色、底边距、是否显示预读句。
- 照片顺序策略（顺序 / 乱序第二遍）。

## 7. 验证
- 渲染后抽查：
  - 时长 ≈ 285s，音画到尾。
  - 抽几个 LRC 时间点截图，确认字幕与歌词、与已知段落对齐。
  - 确认竖照片无裁脸、横照片铺满。
- 现场前在目标笔记本/投影上整段试播一次。

## 8. 非目标 (YAGNI)
- 不做逐字卡拉OK高亮（按行高亮足够）。
- 不做现场网页播放器。
- 不做照片自动人脸检测/智能裁剪（模糊补边已规避裁脸问题）。
